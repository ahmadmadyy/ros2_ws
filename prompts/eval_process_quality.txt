## Evaluation Rubric

Score each dimension 1–5. For every criterion with a numeric threshold table, cite the relevant pre-computed metric value in your justification.

---

### A. Process Analysis Quality

**1. Process Analysis Accuracy** (1–5)
Did the process quality reasoning correctly identify the repeatability characteristics, takt time breakdown, and production-readiness issues?
- Score 5: Correctly identified all significant variation sources; takt time breakdown is accurate; production-readiness assessment matches the actual metrics
- Score 4: Mostly accurate; one minor misidentification or omission
- Score 3: Some correct observations but missed a significant variation source or made an incorrect process capability claim
- Score 2: Superficial analysis; key repeatability issues were overlooked
- Score 1: Analysis inconsistent with what the trajectory data shows

---

### B. Cycle Repeatability

**2. Cycle Duration Uniformity** (1–5)
In a production line, all screwing cycles must execute in the same time. High CoV means the robot behaves unpredictably — unacceptable for a controlled process.
Use `{metrics_cw_duration_cov}`% coefficient of variation of CW stroke durations.

| Score | CW stroke duration CoV |
|-------|------------------------|
| 5 | < 3% |
| 4 | 3 – 6% |
| 3 | 6 – 15% |
| 2 | 15 – 40% |
| 1 | ≥ 40% or only one cycle detected |

**3. Engage Position Repeatability** (1–5)
In production, the screwdriver must re-engage the screw head at the exact same position every cycle. Drift across cycles means the torque delivery angle changes — a process defect.
Use `{metrics_engage_repeatability}` — extract the **worst-joint** maximum deviation across all engage positions.
If the value is "N/A", assign score 2.

| Score | Worst-joint max deviation across all engage positions |
|-------|-------------------------------------------------------|
| 5 | < 0.003 rad |
| 4 | 0.003 – 0.010 rad |
| 3 | 0.010 – 0.030 rad |
| 2 | 0.030 – 0.100 rad |
| 1 | ≥ 0.100 rad |

---

### C. Process Output Accuracy

**4. CW Rotation Completeness** (1–5)
In production, the total screw rotation must match the specification exactly. Under-rotation means the screw is not driven to the required depth; over-rotation risks stripping.
Use `{metrics_total_cw_deg}`° actual vs `{metrics_expected_cw_deg}`° expected.
Compute deviation = |actual − expected| / expected × 100.

| Score | Deviation from specified CW rotation |
|-------|--------------------------------------|
| 5 | ≤ 2% |
| 4 | 2 – 5% |
| 3 | 5 – 15% |
| 2 | 15 – 30% |
| 1 | > 30% |

**5. Return-to-Home Precision** (1–5)
The end-of-line state must match the start-of-line state exactly for the cell to be sequenced into a production line.
Use `{metrics_home_error_l2}` rad L2 error.

| Score | Return-to-home L2 error |
|-------|--------------------------|
| 5 | < 0.003 rad |
| 4 | 0.003 – 0.010 rad |
| 3 | 0.010 – 0.030 rad |
| 2 | 0.030 – 0.080 rad |
| 1 | ≥ 0.080 rad |

---

### D. Stroke Consistency

**6. CW Step Consistency** (1–5)
Each CW step should increment wrist_3 by exactly {screw_step_rad} rad. Inconsistent step sizes indicate controller irregularities or trajectory interpolation errors that affect torque delivery per step.
Examine the CW stroke segments in the trajectory. Estimate whether j6 increments are uniform across steps.

| Score | Description |
|-------|-------------|
| 5 | All CW steps appear uniform — no visible variation in j6 increment size across all steps in all cycles |
| 4 | Very minor variation (one or two steps slightly different) but overall highly consistent |
| 3 | Noticeable but not severe variation — most steps consistent but some outliers |
| 2 | Significant step size variation across cycles or within a cycle |
| 1 | Highly irregular step sizes — no consistent CW increment |

---

### E. Production Time Efficiency

**7. Productive Time Fraction** (1–5)
A production line measures OEE (Overall Equipment Effectiveness). Productive time fraction is the direct robot-analog of the performance component of OEE.
Use `{metrics_productive_pct}`% productive CW screwing time.

| Score | Productive screwing time fraction |
|-------|-----------------------------------|
| 5 | > 65% |
| 4 | 50 – 65% |
| 3 | 35 – 50% |
| 2 | 20 – 35% |
| 1 | ≤ 20% |

---

## Critical Failure Conditions

Flag as a **critical failure** if ANY of the following are detected:
1. Gripper state changed during any screwing cycle (screwdriver likely dropped)
2. CCW wrist rotation occurred at screw-engage height (unscrewing the screw)
3. Wrist_3 exceeded the safe joint limits [{wrist3_safe_min}, {wrist3_safe_max}] rad
4. Fewer than 1 complete CW stroke was executed
5. Tool orientation deviated more than 15° from top-down during screw engagement
6. Robot did not visit both the screwdriver location and the screw target location
