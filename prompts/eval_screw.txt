## Evaluation Rubric

Score each dimension 1–5. Cite the relevant pre-computed metric value in your justification wherever a numeric threshold table is provided.

---

### A. Reasoning Quality

**1. Spatial Awareness** (1–5)
Does the reasoning correctly identify the screwdriver and screw target positions, the top-down grasp requirement, and the spatial layout of the workspace?

**2. Phase Identification** (1–5)
Does the reasoning accurately segment the trajectory into pick, screw, and return phases with correct timestep boundaries?

**3. Screwing Mechanics Understanding** (1–5)
Does the reasoning demonstrate understanding of the CW/CCW cycling strategy, why joint-range limits force repeated lift-reposition cycles, and the relationship between step size and total rotation per stroke?

**4. Safety Awareness** (1–5)
Does the reasoning account for joint limit margins, gripper stability throughout screwing, and the constraint that CCW rotation must only occur while lifted?

---

### B. Trajectory Quality — Pick Phase

**5. Grasp Execution** (1–5)
| Score | Description |
|-------|-------------|
| 5 | Top-down approach, correct grasp height, gripper closes to 0.57 rad (±0.03), clean vertical retreat with no lateral drift |
| 4 | Correct approach and height but gripper slightly off (±0.06 rad) or minor positional offset at grasp |
| 3 | Minor misalignment or gripper value outside ±0.06 rad, but grasp likely functional |
| 2 | Noticeable misalignment or gripper variation suggesting unreliable grasp |
| 1 | Wrong approach angle, wrong height, or gripper did not close appropriately |

**6. Pick-to-Screw Transition** (1–5)
| Score | Description |
|-------|-------------|
| 5 | Direct path, top-down orientation maintained continuously, no redundant waypoints |
| 3 | Minor orientation deviation or a small detour, but arrives at screw target correctly |
| 1 | Large detour, orientation flip, or path suggesting potential collision |

---

### C. Trajectory Quality — Screwing Phase

**7. Screw Engagement** (1–5)
| Score | Description |
|-------|-------------|
| 5 | Precise XY alignment at screw target, correct engage Z height, top-down orientation preserved at all engage events |
| 4 | Correct XY and Z but minor orientation deviation (< 5°) at one engage event |
| 3 | Slight positional offset (screwdriver tip likely still contacts screw head) |
| 2 | Moderate misalignment — tip contact uncertain |
| 1 | Clearly misaligned in XY, wrong Z, or orientation lost |

**8. CW Stroke Joint Isolation** (1–5)
Use `{metrics_cw_drift_per_block}` — extract the worst-block max drift value and apply the table below.

| Score | Worst-block max drift (j1–j5 combined) |
|-------|----------------------------------------|
| 5 | < 0.005 rad |
| 4 | 0.005 – 0.020 rad |
| 3 | 0.020 – 0.050 rad |
| 2 | 0.050 – 0.100 rad |
| 1 | ≥ 0.100 rad |

Also verify: j6 is monotonically increasing during each CW block (correct direction); each step is approximately {screw_step_rad} rad.

**9. Lift-Reposition-Reengage Quality** (1–5)
| Score | Description |
|-------|-------------|
| 5 | Every cycle: j1–j5 change for lift, j6 stays at CW-end value; j6 resets to safe_min while lifted; j1–j5 return to engage position for lower — all 5 cycles |
| 4 | All cycles structurally correct; one minor positional deviation at re-engage < 0.02 rad |
| 3 | Mostly correct but one cycle has sequencing or positional issue |
| 2 | Two or more cycles with problems, or one cycle where CCW occurred at wrong height |
| 1 | CCW at engage height (unscrewing), failed re-engage, or gross position error |

**10. Cycle Rotation Accuracy** (1–5)
Use `{metrics_total_cw_deg}`° actual vs `{metrics_expected_cw_deg}`° expected.
Compute deviation = |actual − expected| / expected × 100.

| Score | Deviation from expected CW rotation |
|-------|--------------------------------------|
| 5 | ≤ 3% |
| 4 | 3 – 8% |
| 3 | 8 – 20% |
| 2 | 20 – 40% |
| 1 | > 40% or fewer than half the cycles completed |

---

### D. Engagement Repeatability

**11. Engagement Repeatability** (1–5)
Use `{metrics_engage_repeatability}`. Extract the worst-joint maximum deviation across all detected engage positions.
If the value is "N/A" (fewer than 2 engage positions detected), assign score 2.

| Score | Worst-joint max deviation across all engage positions |
|-------|-------------------------------------------------------|
| 5 | < 0.005 rad |
| 4 | 0.005 – 0.015 rad |
| 3 | 0.015 – 0.050 rad |
| 2 | 0.050 – 0.100 rad |
| 1 | ≥ 0.100 rad |

---

### E. General Motion Quality

**12. Motion Smoothness** (1–5)
Use `{metrics_peak_w3_vel}` rad/s for the primary threshold. Also check non-wrist joints for abrupt transitions.

| Score | Peak wrist_3 velocity |
|-------|-----------------------|
| 5 | < 0.50 rad/s |
| 4 | 0.50 – 1.00 rad/s |
| 3 | 1.00 – 1.50 rad/s |
| 2 | 1.50 – 2.00 rad/s |
| 1 | ≥ 2.00 rad/s |

**13. Task Efficiency** (1–5)
Use `{metrics_productive_pct}`% productive screwing time out of {metrics_total_duration}s total.

| Score | Productive screwing time fraction |
|-------|-----------------------------------|
| 5 | > 65% |
| 4 | 50 – 65% |
| 3 | 35 – 50% |
| 2 | 20 – 35% |
| 1 | ≤ 20% |

## Critical Failure Conditions

Flag as a **critical failure** if ANY of the following are detected:
1. Gripper state changed during any screwing cycle (screwdriver likely dropped)
2. CCW wrist rotation occurred at screw-engage height (unscrewing the screw)
3. Wrist_3 exceeded the safe joint limits [{wrist3_safe_min}, {wrist3_safe_max}] rad
4. Fewer than 1 complete CW stroke was executed
5. Tool orientation deviated more than 15° from top-down during screw engagement
6. Robot did not visit both the screwdriver location and the screw target location

---

## Scoring Weights

Compute `overall_score` as the weighted average of all 13 scores:

| Criterion | Weight |
|-----------|--------|
| CW Stroke Joint Isolation (criterion 8) | 18% |
| Cycle Rotation Accuracy (criterion 10) | 14% |
| Engagement Repeatability (criterion 11) | 14% |
| Lift-Reposition-Reengage Quality (criterion 9) | 10% |
| Screw Engagement (criterion 7) | 9% |
| Grasp Execution (criterion 5) | 8% |
| Motion Smoothness (criterion 12) | 7% |
| Task Efficiency (criterion 13) | 5% |
| Consistency — Reasoning vs Trajectory | 5% |
| Safety Awareness (criterion 4) | 4% |
| Screwing Mechanics Understanding (criterion 3) | 3% |
| Phase Identification (criterion 2) | 2% |
| Spatial Awareness (criterion 1) | 1% |

For criterion 13 "Consistency": score 5 if reasoning phase boundaries, rotation directions, and positions closely match the trajectory; score 3 if generally aligned but some mismatch; score 1 if reasoning describes a fundamentally different trajectory.
