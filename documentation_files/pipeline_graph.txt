--- Pairing Table ---

Each Cosmos prompt feeds exactly one eval prompt. The pairing is
one-to-one and fixed — no cross-evaluation between prompts.

    Cosmos Prompt                   Eval Prompt                   Slug
    ─────────────────────────────   ─────────────────────────── ──────────────
    cosmos_screw.txt             → eval_screw.txt                screw
    cosmos_fault_detection.txt   → eval_fault_detection.txt      fault_detection
    cosmos_energy_dynamics.txt   → eval_energy_dynamics.txt      energy_dynamics
    cosmos_process_quality.txt   → eval_process_quality.txt      process_quality


--- Data Flow Per Pair ---

For each pair, the eval prompt receives two inputs:

    1. The Cosmos text output (the model's free-form analysis)
    2. The same trajectory JSON that Cosmos received

Llama reads both side by side. It uses the trajectory as ground
truth to verify the claims in the Cosmos output, then scores
across the 13 rubric dimensions.
