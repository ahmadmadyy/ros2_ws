## Analysis

### 1. Joint Velocity Profile
For each consecutive pair of timesteps compute ω_i(t) = (θ_i(t+1) − θ_i(t)) / Δt.
Classify each segment as: **Stationary** (<0.01 rad/s) | **Slow** (0.01–0.5) | **Moderate** (0.5–2.0) | **Fast** (>2.0).
Produce a compact per-joint timeline with direction (+/−).

### 2. Change-Point Detection
List every timestep where:
- A joint transitions between motion categories
- The gripper state changes
- The dominant active joint switches

For each: timestep, which joint(s), nature of change.

### 3. Activity Inference
Map each segment to an activity using these signatures:

| Motion Signature | Inferred Activity |
|---|---|
| Joints 1–3 moving, gripper open | Arm repositioning / approach |
| Joints 1–3 downward, gripper open | Descending to grasp |
| Gripper state open→partial | Grasping screwdriver |
| Joints 1–3 upward, gripper closed | Lifting / retreating with tool |
| Only wrist_3 CW, others stationary, gripper closed | Active screwing stroke |
| Joints 1–3 upward, wrist_3 stationary, gripper closed | Lift to disengage |
| Only wrist_3 CCW, others stationary, gripper closed | Wrist reposition |
| Joints 1–3 downward, gripper closed | Re-engaging screw |

For each segment: timestep range, active joints, velocity category, inferred activity, confidence (HIGH/MEDIUM/LOW).

### 4. Anomaly Detection
Flag: velocity spike (|ω|>5 rad/s), multi-joint screwing (other joints >0.05 rad/s during CW stroke), wrong-direction screwing, gripper instability, stall (>2 s stationary unexpectedly), limit approach (<0.1 rad from limit).
For each: timestep, joint, observed value, expected, severity (CRITICAL/WARNING/INFO).

### 5. Screwing Effectiveness
From wrist_3 velocity profile: number of CW segments, total CW displacement (rad and degrees), total CCW displacement, net rotation, average CW and CCW velocities.

### 6. Corrective Feedback
For each anomaly found, state the specific correction.

## Common Structured Output

After completing the analysis above, output **only** this JSON block. Every field is required. Do not add extra fields.

```json
{
  "task_success":        {"score": <1-5>, "justification": "<one sentence>"},
  "phase_correctness":   {"score": <1-5>, "justification": "<one sentence>"},
  "screwing_quality":    {"score": <1-5>, "justification": "<one sentence>"},
  "anomaly_severity":    {"score": <1-5>, "justification": "<one sentence — 5=none found, 1=critical failure>"},
  "corrective_guidance": {"score": <1-5>, "justification": "<one sentence>"},
  "overall_score": <float 0.0-1.0>,
  "critical_failures": ["<string describing failure 1>", "<string describing failure 2>"],
  "recommended_waypoints": [
    {
      "phase": "<phase name>",
      "joints": [j1, j2, j3, j4, j5, j6],
      "gripper": <0.0-1.0>,
      "velocity_scaling": <0.0-1.0>,
      "note": "<what this waypoint improves or confirms>"
    }
  ]
}
```

Rules:
- `critical_failures`: array of short strings (one sentence each). Include **only CRITICAL severity** issues. Maximum 5 entries. If no critical failures, use `[]`.
- `recommended_waypoints`: 1–3 waypoints maximum. If no issues, include the ideal S7:ENGAGE_SCREW waypoint at {screw_position}, tool0-z={grasp_z} m. If critical failures exist, one corrective waypoint per failure.
- Score guide: 5=excellent, 4=good, 3=acceptable, 2=poor, 1=critical failure.
- `overall_score` = (task_success×0.30 + phase_correctness×0.20 + screwing_quality×0.25 + anomaly_severity×0.15 + corrective_guidance×0.10) / 5.0
